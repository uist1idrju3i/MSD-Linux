# 和柄（日本の伝統文様）の調査とロゴ・サイトでの採否

MSD/Linux のロゴ（[意匠](../logo/README.md#意匠)）と公式サイト（`docs/`）に使う文様を選ぶために、14 種類の文様と、文様の分類を調べた記録です。名前の由来は [RESEARCH.md の「名称」](../../RESEARCH.md#名称)にまとめています。

## 1. 選ぶときの条件

- 主題とのつながり: 名前の由来である室見川と、室見川が注ぐ博多湾を表せること。
- 小さな画面での読みやすさ: CardputerZero の LCD（320×170）と 32 ピクセルのアイコン、375px 幅のスマートフォンでも潰れず、ちらつかないこと。
- 本文を邪魔しないこと: 文字の背景に敷いても、読みにくくならないこと。
- 控えめな装飾: 使う文様の数を絞り、ページ全体を文様で埋めないこと。

## 2. 文様の分類

- 文様は大きく、写実的なものと抽象的なものに分けられます。写実的な文様が、しだいに抽象化されて幾何学的な文様になることもあります（[コトバンク「文様」](https://kotobank.jp/word/%E6%96%87%E6%A7%98-143369)）。
- 自然文様は、太陽、月、雲、山水などの自然物を元にした文様です。割付文様は、単位となる文様を縦横の線の交点に規則的に割り付けて一面を埋める文様で、青海波・立涌・七宝・亀甲・籠目・鱗・麻の葉などがあります（[慶應義塾大学 SFC 箕原辰夫「Patterns with Turtle Graphics」](http://web.sfc.keio.ac.jp/~minohara/lecture/logical/columns/patterns.html)、[粋屋「割付文様一覧」](http://www.ikiya.jp/crest/warituke/top.html)）。
- 吉祥文様は、祝意や縁起のよさを表す文様の総称です。日本国語大辞典は、例の一つに青海波を挙げています（[コトバンク「吉祥文様」](https://kotobank.jp/word/%E5%90%89%E7%A5%A5%E6%96%87%E6%A7%98-474575)）。

一つの文様が複数の分類に入ることがあります。たとえば青海波は、波を元にした自然文様でもあり、割付文様でもあり、吉祥文様でもあります。

## 3. 文様ごとの調査と採否

| 文様 | 由来と意味 | ロゴ・サイトに使ったとき | 採否 |
|---|---|---|---|
| 青海波 | 同心円の弧を鱗状に並べた波文様。舞楽「青海波」の装束に使われたことから名が付いたといわれる。古代ペルシアにも同様の文様があり、日本へは奈良時代ごろに伝わったとされる。無限に広がる波に、未来永劫へ続く幸せを込めた縁起のよい文様（[NDL イメージバンク「模様が意味するもの」](https://www.ndl.go.jp/imagebank/column/moyo)、[コトバンク「青海波文」](https://kotobank.jp/word/%E9%9D%92%E6%B5%B7%E6%B3%A2%E6%96%87-85546)、[立命館大学 ARC 型紙プロジェクト「青海波」](https://www.arc.ritsumei.ac.jp/lib/GCOE/isekata/2015/07/post-128.html)） | 横に切れ目なく連続するので、帯にしやすい。段数を抑えれば小さな画面でも潰れない | 採用: ロゴ下部とサイト下端の帯（博多湾） |
| 流水 | 流水をかたどった文様。弥生時代の土器や銅鐸の流水文があり、近世以降は観世水などの染織の意匠に多く使われた。弥生時代の流水文は、近世の水の表現に似ることから名が付いたもので、水を表したとは限らない（[コトバンク「流水文」](https://kotobank.jp/word/%E6%B5%81%E6%B0%B4%E6%96%87-149676)） | 細い数本の線で描けるので、文字の邪魔にならない | 採用: ロゴの三本の流れと、サイトの見出しの区切り（室見川） |
| 枯山水の砂紋 | 白砂に描く筋で、水を使わずに水の流れや波を表す。青海波紋・流水紋・やり水紋・水紋などの種類がある（[佛教大学 公開講座「枯山水における砂紋の美しさ」](https://www.bukkyo-u.ac.jp/olc/pickup/20240718/27395.html)、[枯山水めぐり「枯山水の砂紋とは？」](https://karesansui.net/324/)） | 線の形は流水・青海波と同じになる | 不採用: 採用した2つと役割が重なる |
| 立涌 | 波状の線が下から上へ湧くように向かい合って並ぶ。立ち昇る様子から運気上昇の意味がある（[日本工芸堂「縁起のいい和柄一覧」](https://japanesecrafts.com/blogs/news/luckypattern)） | 縦に流れるので、横書きの本文と向きが合わない | 不採用 |
| 七宝 | 同じ大きさの円を均等に重ねてつなぐ。円（縁）が四方へ広がる様子から「円満」に通じる（日本工芸堂） | 面を埋める文様で、帯にすると線が細かく、地と混ざった（サイトの試作 C 案） | 不採用 |
| 市松 | 二色の正方形を碁盤の目のように組み合わせる。江戸中村座の佐野川市松が使ったことから名が付いた。上下左右に続くことから繁栄の願いも込められる（日本工芸堂） | 二色の面が強く、文字の背景にならない | 不採用 |
| 鱗 | 二色の三角形を交互に並べて鱗に見せる。蛇の鱗を表すとされ、厄除けの意味がある（日本工芸堂） | 市松と同じく、二色の面が強い | 不採用 |
| 麻の葉 | 麻の葉と正六角形を幾何学的に組み合わせる。成長の早い麻にあやかって子の成長を願い、産着に使う魔除けの風習があった（日本工芸堂） | 線が多く、小さな画面ではちらつく | 不採用 |
| 亀甲 | 亀の甲羅のように六角形を合わせる。長寿の象徴（日本工芸堂） | 麻の葉と同じく、線が多い | 不採用 |
| 籠目 | 竹籠の網目を元にした文様。魔除け・厄除けの意味がある（日本工芸堂） | 麻の葉と同じく、線が多い | 不採用 |
| 矢絣 | 矢羽根を表す。まっすぐ飛ぶ矢から「出戻らない」の意味がある（日本工芸堂） | 主題（川と海）と結びつかない | 不採用 |
| 唐草 | つる草が四方へ伸びる様子。子孫繁栄や長寿の願いが込められる（日本工芸堂） | 線が多く、にぎやかになる | 不採用 |
| 組紐 | 束ねた糸を斜めに交差させて紐状に組んだ工芸品。断面の形で丸打・平打・角打に分けられる（[奈良国立博物館 正倉院展用語解説「組紐」](https://shosointen-glossary.narahaku.go.jp/kumihimo/)）。亀甲組・唐組などの組み方の柄がある（[台東区「伝統の美術工芸・組紐」](https://www.culture.city.taito.lg.jp/bunkatanbou/craft/kumihimo/japanese/page_01.html)） | 平面の文様というより組み方の柄で、主題とも結びつかない | 不採用 |

## 4. 結論

- 室見川を流水、博多湾を青海波で表します。川が海へ注ぐという一つの話を、ロゴでは一つの図の中で、サイトではページを読み進める順に（見出しの流水 → 下端の青海波）表します。
- サイトでは、この2つ以外の文様は使いません。背景を文様で埋めることもしません。
- サイトの試作では、A 案（見出しに流水、下端に青海波）を、B 案（冒頭にも薄い青海波を敷く）と C 案（下端を七宝にする）と比べて選びました。B 案は 375px 幅でほとんど見えず、効果が小さいので採りませんでした。

## 5. 出典の扱い

- 由来の説には諸説があるものを含みます。NDL イメージバンクは、青海波の名の由来を「諸説があり定かではありません」としています。ロゴとサイトの説明では、由来を言い切らずに「とされる」「といわれる」と書きます。
- 日本工芸堂は工芸品を販売する事業者の記事です。文様の意味の説明に使い、歴史上の事実の根拠には使いません。
