ポケットに入る小さなコンピューター「CardputerZero」のための、すぐ起動して壊れにくい OS を作っています。

MSD/Linux でできること

  • 電源を入れたら、すぐ使える待たずに文字を打ち始められるよう、起動までの時間を短くします。
  • 急に電池が切れても壊れにくいいつ電源が落ちても、次に起動すれば元どおりに使えるようにします。
  • 更新に失敗しても、元に戻る新しいバージョンで起動できなければ、自動で前のバージョンに戻ります。
  • 付いている機能を削らずに使える画面、キーボード、音、カメラ、無線などを、速さのために削りません。
  • 費用に見合う守りを備える盗まれたり、いたずらされたりしたときに備え、効果の大きい対策から入れます。
  • 確かめたことだけを書く確かめたことと、まだ確かめていないことを分けて公開します。

開発の状況

開発中です。まだ、ふだん使える状態ではありません。CardputerZero の実機では、まだ動作を確かめていません。

いまは、パソコンの中で CardputerZero に近い環境を再現して（エミュレーター）、起動や更新を試しています。画面、キーボード、実際の電源断などは、実機が届いてから確かめます。

名前とロゴの由来

MSD は Muromi Software Distribution の頭文字です。開発場所の近くを流れる室見川（むろみがわ）から名前をとりました。

この名付け方は、SSD/Linux にならったものです。SSD/Linux は、開発者が中学3年生だった 2004 年に初めて触れた Linux で、開発場所の外神田（そとかんだ）から名前をとっていました。

室見という名前には、もう一つ由来があります。開発者が好きなライトノベル『なれる!SE』（夏海公司）に登場するシステムエンジニア、室見立華（むろみ りっか）です。

ロゴは、室見川が博多湾へ注ぐ姿を、伝統的な文様の流水と青海波で描いています。このページの見出しの下にある線は流水、いちばん下の波は青海波です。

技術者の方へ

MSD/Linux は、Buildroot で作る M5Stack CardputerZero（Raspberry Pi CM0）向けの Linux ディストリビューションです。LCD のテキストコンソールと内蔵キーボードで操作する CLI を提供します。設計の柱は次の6つです。

すぐ使える
firmware とカーネルの設定を最適化し、起動に要らないドライバーはモジュールにします。改善は実測で確かめます。
電源断で壊れない
rootfs は読み取り専用の SquashFS にし、書き込みを ext4 の /data に限ります。
更新に失敗しても戻れる
A/B の2スロットと、Raspberry Pi firmware の tryboot・autoboot.txt で、試験起動に合格したときだけ新しいバージョンを確定します。
ハードウェアをすべて使える
起動に必須のものだけを組み込み、ほかはモジュールとして必要なときに読み込みます。
費用に見合うセキュリティ
取り外せる microSD があり、ハードウェアの secure boot がない端末であることを前提に、カーネルのハードニングや更新イメージの署名を入れます。
検証できる
CI で Buildroot のビルドと QEMU での起動を確かめ、QEMU で確かめたことと実機でしか確かめられないことを分けて記録します。

バージョン番号や測定値は、リポジトリの文書にだけ書いています。
