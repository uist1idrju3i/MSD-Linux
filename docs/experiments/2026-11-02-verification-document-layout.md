整理前の採否条件は、元の条件・否定・数値・URL・失敗記録を失わないことです。本文を移す部分はリンク先を同じ意味に換算して全文を保存し、重複する問いと訂正する状態は原記録CSVへ保存します。過去の測定CSVは変更しません。5回の決定的な保存照合と改変対照を行います。性能比較ではないので、処理時間の中央値や速度改善率は出しません。

- 観測・実機測定・基盤比較・履歴の9本文を保存しました。追加した現在の説明を除き、相対リンクを同じ対象へ解決し、空白文字だけの行を空行へ正規化した元の本文全体が移動先に含まれることを照合します。元3文書の全ての空行でない行も、移動先か原記録にあることを照合します。

## 再実行

環境はLinux `6.8.0-1061-aws`、x86_64、Python `3.12.13`、Git `2.34.1`です。QEMUと製品buildは使っていません。基準commitの元3文書を読めるcloneで[照合スクリプト](2026-11-02-verification-document-layout.py)を実行します。出力先には新しい名前を指定します。

```sh
python3 docs/experiments/2026-11-02-verification-document-layout.py \
  --base 4aa7ec1940d5faf1c341ff9ad510f878570b036a \
  --output verification-document-layout-new.csv
```

スクリプトは元のgit objectから本文を読みます。原記録の各行と見出し、問い79件、S1–S17の一意な順序、移動した9本文、元の空行でない行、過去の測定CSV51ファイルを照合します。数値だけの抽出ではありません。UARTの値の変更、カメラの確認条件の削除、問いIDの欠落、原記録の書き換えをメモリー上で与え、拒否することも確認します。実際の文書や測定CSVは改変対照で変更しません。

## 結果・失敗した試行

[全結果CSV](2026-11-02-verification-document-layout.csv)に入力・出力のSHA-256、期待値、状態、失敗箇所を保存します。5回の保存照合は成功し、4種類の改変を拒否しました。過去の測定CSV51ファイルは基準と同一です。

初回の問いの抽出では、表の見出し3行も問いとして数えました。表の見出しを除外し、元の行と照合して79件へ直しました。最初のリンク検査は、新規ファイルをindexへ加える前のため参照先を見つけられず失敗しました。その後、設計履歴に残った移動前のローカルanchor2件を修正しました。DeepWikiの文章で2個のパスを空白なしの「と」で連結した箇所も、パスとして誤認されるため区切りました。これらを初回から成功とは扱いません。

その後のstaged差分の空白検査は、移した本文の空白1文字の行で失敗しました。未stage差分の検査だけでは検出できていませんでした。空行へ直し、保存照合も空白文字だけの行を正規化する形で再実行しました。[空行訂正後の全結果](2026-11-02-verification-document-layout-v2.csv)でも5回成功・4改変拒否です。初回CSVは変更せず、[提出前の追加検査](2026-11-02-verification-document-layout-checks-v2.csv)にstaged検査の初回失敗と再検査を分けて記録します。

ホストのShellCheck `0.8.0`は、既存の`guest-dump.sh`のstderrを含む採取処理にSC2002を出しました。この変更でシェルを編集したものではありません。固定した開発用コンテナーのShellCheck `0.11.0`では、追跡する全シェルの検査が成功しました。検査対象の除外やゲートの緩和はしていません。

[提出前の全終了状態](2026-11-02-verification-document-layout-checks.csv)に、5種の文書検査と各回帰試験、既存更新20件のhost試験、Python構文検査、固定OCIのactionlint・ShellCheck、offline zizmor、差分の空白検査を記録しています。終了値0と、過去からある文字・サイズの警告を区別します。

## 推敲と限界

日本語はyomiyasuのCLIで検査し、原文と根拠を読み比べました。「台帳」「解像度」はそれぞれ試験の管理表とカメラの値を指します。保存した条件や当時の箇条書きを、語彙・強調・リスト比率の警告を消すためだけには変更しません。新しい参照先・名称の警告はリンクと現行文書へ戻って確認しました。機械検査の実行を、意味や読みやすさの認定とはしません。

この照合は今回の再配置時点の保存確認です。将来の本文改訂後も同じ結果になる回帰試験ではありません。主題別にまとめた現在の説明の意味や、元の主張の正しさは、保存の一致だけでは判定できません。過去のQEMU結果・実機測定・代替構成を再実行した検証ではなく、実機のfirmware・周辺機能・電断・SD性能は未確認のままです。全文書・公開サイトの整理完了も意味しません。
