## 事前の基準

基準git objectの3原稿について、H1を除いた本文全範囲を、意味のまとまりに沿って移動本文と要約の原文記録に割り当てます。本文のURLはリンク先を同じリポジトリの位置に正規化して照合し、空白だけの行を揃えます。それ以外の数値、条件、否定、引用、出典、失敗記録を変えません。要約の原文・hash・統合理由・対応先はCSVの全列を照合します。

本文全範囲に欠落・重複がないこと、基準のCSV全件がbyte同一であることを5回確認します。初期化や破壊的操作のある試験ではなく、同じ原文に対する決定的な静的照合です。起動時間やOSの性能へ結論を転用しません。

applet数、sort優先度、libcの公表値、S6値、module禁止条件、署名と時刻、監視案のRAM条件、要約の否定をそれぞれ変える対照を設けます。要約の1行削除と、本文対応の欠落も検出します。採否の基準は保存照合のエラー0件、全10対照の検出、リンク・文字・サイズ等の関連検査の失敗0件です。本文サイズは20,000 byte超を意味単位で再評価し、40,000 byte超にはしません。
