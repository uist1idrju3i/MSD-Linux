# kbdの未使用tool削減

- 状態: 計画
- 日付: 2026-11-23
- 担当: Devin
- 関連: [kbdの選択肢](../research/component-options/kbd.md)

## 目的と採否の基準

候補1・2を適用済みの現行構成CI imageを変更前とし、loadkeys以外の未使用kbd toolだけを除く。
rootfs通常file合計とSquashFSの両方が1 byte以上減り、loadkeys・keymap・他の残存fileの内容が不変なら容量面で採用する。
変更前後のA/B全4 bootでkeymap読込みの終了0、ready/login、QMP quit・reap・終了0を要求する。
全4 bootのmodule名・サイズ・依存・状態が一致することも要求する。参照数・addressは比較しない。
容量削減を起動時間の短縮と扱わず、QEMUのkeymap読込みをM5実機のkeyboard動作と扱わない。
